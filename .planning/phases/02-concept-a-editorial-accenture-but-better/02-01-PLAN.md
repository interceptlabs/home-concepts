Copy gate contract (qa/copy-diff.py, verified from source):
- `data-copy="dot.path"` must resolve through content/homepage.json to a STRING leaf. Arrays/objects are hard FAILs — always index to the leaf (`problems.items.0.tells.0`, never `problems.items.0.tells`).
- The extractor accumulates ALL descendant text of the annotated element, so nested inline markup (an `<a>` or `<em>` inside an annotated `<p>`) is fine as long as the combined visible text matches the canonical string exactly (whitespace-normalized).
- `_html`-suffixed fields (hero.h1_html, labs.h2_html) are tag-stripped on both sides — the element's inline tag structure is free, only visible words must match.
- Duplicate dot-paths on one page are fine — each element is checked independently.
- NEVER nest one data-copy element inside another (the outer chunk would accumulate the inner's text and fail).
- hrefs are NEVER copy-checked — repoint `#pitchLabs`/`#convoDrawer` freely.
- Copy-paste every string from content/homepage.json. Never retype: canonical copy uses curly quotes (’ “ ”), × and em dashes; a straight-quote retype is an exact-match FAIL.
- CSS text-transform is legal styling (DOM text stays verbatim); changing the actual text case is not.
