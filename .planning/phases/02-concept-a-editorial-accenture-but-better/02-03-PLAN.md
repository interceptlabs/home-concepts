Motion tokens (shared/motion.css — the ONLY timing values allowed):
```css
--ease-inout-sine: cubic-bezier(0.37, 0, 0.63, 1);
--dur-short: 400ms;  --dur-med: 800ms;  --dur-long: 1400ms;
```
CONTEXT locks 600-900ms reveal durations → use `var(--dur-med)` (800ms).

No-JS / reduced-motion safety pattern (locked — the research example hides content by default, which breaks no-JS; use this instead):
- Each page's `<head>` gets a one-line bootstrap BEFORE the stylesheets take effect on paint: `<script>document.documentElement.classList.add('has-js')</script>`
- All hide-then-reveal CSS is scoped under `.has-js` — e.g. `.has-js [data-reveal] { opacity: 0; … }` — so JS-off users see everything immediately.
- `@media (prefers-reduced-motion: reduce)` additionally forces `[data-reveal]`, hero lines, and hover accents to their final visible state with `transition: none; animation: none;`.
- motion.js ALSO checks `matchMedia('(prefers-reduced-motion: reduce)')` and, when reduced, adds `.is-visible` to everything without observing (belt and braces, per research Pattern 5).

Copy safety: adding attributes (`data-reveal`) and wrapper spans inside the annotated hero h1 never changes visible text — but any accidental text edit fails the gate, so copy-diff re-runs on every touched page in this plan's verifies.
