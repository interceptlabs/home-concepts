EVERYTHING that touches document/window lives inside a `boot()` called behind `if (typeof document !== 'undefined') boot();` so Node can import the module headlessly.

**Bootstrap decision tree (RESEARCH Pattern 1 + Code Examples, exactly):**
- `hasWebGL2()`: throwaway canvas `getContext('webgl2')` probe wrapped in try/catch, AND'd with `window.WebGL2RenderingContext`. Support the test hook: `new URLSearchParams(location.search).has('nowebgl')` forces failure.
- Probe fails -> `documentElement.classList.add('no-webgl')`, return — no renderer, no canvas, ever.
- Probe passes + `matchMedia('(prefers-reduced-motion: reduce)').matches` -> add `webgl static-scene`, `initScene({ animated: false })`: full scene built, ONE render at a pulled-back overview framing showing all 6 objects, labels projected once, re-projected + re-rendered on resize only, DPR forced to 1, no rAF loop, no parallax. (Locked call: frozen 3D scene, not the flat backdrop. 04-03 refines the framing.)
- Otherwise -> add `webgl`, `initScene({ animated: true })`.

**Renderer/scene init:** create the canvas via `document.createElement('canvas')`, `aria-hidden` handled by the mount; append into `.scene-mount`. `new THREE.WebGLRenderer({ canvas, antialias: true, powerPreference: 'low-power' })`. DPR clamp: `renderer.setPixelRatio(matchMedia('(max-width: 768px)').matches ? Math.min(devicePixelRatio, 1.5) : Math.min(devicePixelRatio, 2))`. Clear color from the --page token. PerspectiveCamera ~50deg fov. Resize listener updates size/aspect and re-renders (must work even when the loop is gated or frozen).

**Token helper:** `readToken(name)` = `getComputedStyle(document.documentElement).getPropertyValue(name).trim()` -> `new THREE.Color(...)`. Materials/clear color ONLY get colors this way — a raw hex string or 0x literal in scene.js is a brand-grep/SSoT violation. (Also: never write `color: #...` even in comments — the grep is line-based.)

**Toon material (RESEARCH Pattern 6 verbatim):** `makeStepGradientMap(steps)` building a `Uint8Array` DataTexture, `THREE.RedFormat`, and CRITICALLY `minFilter = magFilter = THREE.NearestFilter` + `needsUpdate = true` — without NearestFilter the hard steps silently become the smooth gradient Fritz forbids (Pitfall 4). Default 4 steps. One shared map; one MeshToonMaterial per object (so the Flarepop accent swap is per-object). Base colors: monochrome grays from --surface, --surface-2, --surface-3 (vary per object for depth).

**The 6 objects (discretion defaults — keep the vocabulary strict):** 3 apex-up right-triangle prisms via `new THREE.Shape()` tracing (0,0)->(w,0)->(0,h) (right angle at base-left, apex up) + `ExtrudeGeometry({ depth, bevelEnabled: false })`, geometry centered; 3 slabs/cubes via BoxGeometry with varying proportions (tall slab, cube, wide slab). Suggested topic mapping: Problems=tall slab, InterceptOS=large prism, Work=cube, Labs=small leaning prism, Insights=wide slab, Contact=prism. Prisms may lean via rotation.z within +/-10 degrees — apex stays up, NEVER inverted (Fritz triangle rule). Spread the field along -Z so the dolly passes each in sequence; composition is your call (record it in the SUMMARY). The Intercept mark itself must NOT appear as scene geometry. Optional calm idle: scroll-focused object only, slow sine y-rotation, long period, +/-5 degrees, skipped when not animated.

**Light rig (discretion default):** one DirectionalLight from upper-front-left + low AmbientLight; tune intensities until the 4 toon bands read clearly on the captures (r185 uses physical lighting units — expect intensity ~2-3 on the directional).

**Camera dolly (RESEARCH Pattern 3 verbatim):** `CatmullRomCurve3` through start-pad + one framing point per topic + end-pad. Every animated frame: `t = clamp(scrollY / (runway.offsetHeight - innerHeight), 0, 1)`; `curve.getPointAt(t, targetPos)`; `smoothPos.lerp(targetPos, 0.08)`; a SECOND CatmullRomCurve3 of lookAt targets (each topic object's position) sampled at the same t and lerped into a smoothLook vector -> `camera.lookAt(smoothLook)`. NO wheel/touchmove/preventDefault anywhere — scrollY is sampled, never intercepted. Deep links + back button work for free because camera is a pure function of scrollY.

**Projected labels (RESEARCH Pattern 4 verbatim, three.js's own manual idiom):** per label binding (topic object <-> `a.topic-label[data-topic]`): `tempV.setFromMatrixPosition(obj.matrixWorld); tempV.project(camera)`; if `Math.abs(tempV.z) > 1` add `.is-hidden` (visibility-hidden class — never display:none), else clear it, set `style.transform = translate(-50%,-50%) translate3d(xpx, ypx, 0)` from NDC->canvas-pixel conversion, and z-index sort by depth.

**Flarepop accent (one at a time):** label mouseenter/focusin -> that object's material color becomes readToken('--flarepop'); mouseleave/focusout -> restore its stored base color. Track the single accented object; a new accent always clears the previous.

**Topic index current-highlight:** from the same t, nearest topic index i = round(t*5); when it changes, move `aria-current="true"` to that index item (and only update DOM on change).

**Render-loop gating (RESEARCH Pattern 2 verbatim — NOT IntersectionObserver, Pitfall 2):** `shouldRun() = !document.hidden && scrollY < runwayHeight + 200`; tick self-reschedules only while shouldRun; `scroll` (passive) + `visibilitychange` + `pageshow` (bfcache return) call ensureRunning(). After the first rendered frame set `documentElement.dataset.sceneReady = '1'`.

**Cursor parallax:** wrap camera in a Group; pointermove maps pointer x/y to a target group rotation of a few degrees, lerped in the tick (sine-feel via the damped lerp). Registered ONLY when `matchMedia('(hover: hover) and (pointer: fine)').matches` and not reduced-motion, and never under `animated: false`.

NO Raycaster anywhere (deferred — labels are the sole click affordance in v1). NO post-processing/bloom (banned).
