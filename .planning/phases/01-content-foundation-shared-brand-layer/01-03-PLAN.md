  <action>
Implement `qa/copy-diff.py`. Structure (model the argparse/report/exit-code discipline on check.py):

**CLI:**
- `python3 qa/copy-diff.py PAGE.html [PAGE2.html ...]` — verify specific pages
- `--all [ROOT ...]` — recursively find `*.html` under the roots (default roots: `concept-a`, `concept-b`, `concept-c`); roots that don't exist yet are skipped with a printed warning (never a crash — concepts land in later phases)
- `--content PATH` — canonical JSON (default: `content/homepage.json` resolved relative to the script's parent's parent, so the gate works from any cwd)
- `--mode auto|annotated|substring` — default `auto`: use annotated mode if the page has any `data-copy` attribute, else substring fallback

**Extraction (class `VisibleTextExtractor(HTMLParser)`):** `convert_charrefs=True`; maintain a skip-depth for SKIP_TAGS = {script, style, svg, symbol, noscript, template} (increment on start tag, decrement on end tag — handle self-closing svg children via HTMLParser's default behavior); collect visible text. Also record, per element carrying `data-copy`, that element's own subtree visible text plus its `data-copy` / `data-copy-truncated` attribute values (track element depth to know when the annotated subtree closes; void elements like img/br inside must not corrupt depth tracking — keep a tag stack).

**Normalization (both sides of every comparison):** strip tags from canonical `_html` values by running them through the same extractor; collapse all whitespace runs to single spaces; strip. Rendered side: strip one trailing ellipsis (`…` or `...`) before truncation checks.

**Annotated mode:** for each data-copy element: resolve the dot-path in the canonical JSON (dict keys, numeric list indices; must land on a STRING leaf — resolving to dict/list or missing key = FAIL "unresolvable/non-string path"). Compare normalized rendered vs normalized canonical: exact equality required, UNLESS `data-copy-truncated="true"` → rendered must be a non-empty exact prefix of canonical AND the canonical character following the prefix must be whitespace/punctuation (word-boundary rule), and prefix != full string is allowed.

**Substring fallback mode:** extract the page's full visible text (normalized). Walk every string leaf in the canonical JSON (record its dot-path); for leaves with normalized length ≥ 40 chars, if the leaf's first 30 normalized chars occur in the page text, the FULL normalized leaf must also occur — else FAIL "detected chunk corrupted: <path>". Pages where nothing is detected PASS with the note "no canonical copy detected".

**Report:** per page: mode used, then per chunk `PASS <path>` or `FAIL <path>` with expected/got and a `difflib.unified_diff` snippet on failure. Final summary line: pages checked, chunks checked, failures. Exit 0 if zero failures, 1 if any failure, 2 on usage/IO errors.

Stdlib only: argparse, json, re, sys, difflib, pathlib, html.parser. Include `if __name__ == "__main__": sys.exit(main())`.
