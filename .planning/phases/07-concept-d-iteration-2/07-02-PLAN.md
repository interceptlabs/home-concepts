From concept-d/assets/js/cards.js (this plan's main edit target):
```javascript
function reparentInto(target){ scaffoldNodes.forEach(n => target.appendChild(n)); } // appends to the DIALOG
// element itself — scaffold nodes become SIBLINGS of .modal-body, so a transform on .modal-body can
// never trap them. A transform on dialog.module-modal WOULD (the Phase-5 invariant).
function openModal(dialog, invoker){ if(!dialog) return; lastInvoker = invoker || lastInvoker;
  reparentInto(dialog); dialog.showModal(); window.dispatchEvent(new Event('resize')); }
// dialog 'close' listener: closeAll() -> ownership-guarded reparent home -> lastInvoker.focus()
// dlg-os delegated listener intercepts a[href="#agents"] -> dlgOs.close() -> openModal(dlgAgents, lastInvoker)
```


View Transition recipe (research-verified, medienbaecker.com + web-standards.dev): assign
`invoker.style.viewTransitionName = 'modal-morph'` → `document.startViewTransition(() => { clear invoker
name; set dialog name; doOpen(); })` → `.finished.finally(() => clear dialog name)`. Close mirrors it
(name back to lastInvoker). Esc fires the dialog's `cancel` event BEFORE close — intercept with
preventDefault() and run the transitioned close, else Esc skips the morph. Sine = cubic-bezier(0.37, 0, 0.63, 1).
